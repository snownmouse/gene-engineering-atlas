## 0. 根问题

这套骨架只回答一个根问题：

> **要得到一个能用的基因工程产品，先后要做哪些决定？每个决定有哪些候选方案，凭什么选？**

所以节点不是「章节」，而是「必须回答的问题」；边不是「讲课顺序」，而是「选了这个方案之后走到哪里」。同一个问题下的并列方案放在同一层，方便横向比较。

---

## 1. 第一层：这门学科要做的六件事

| 编号 | 问题 | 要得到的结果 | 不通过时回到哪里 |
|---|---|---|---|
| N01 | 拿到目的基因 | 一段序列明确、来源可靠的 DNA | 回到 N01 换获取路线 |
| N02 | 把基因装进载体 | 一个能复制、能筛选、必要时能表达的重组分子 | 回到 N02 换载体或换连接方式 |
| N03 | 把它送进宿主 | 带重组分子的活细胞 | 回到 N03 换宿主或换导入方法 |
| N04 | 确认真的拿到了 | 有证据证明重组子正确 | 回到 N02/N03 重切、重接、重转 |
| N05 | 让它表达 | 有活性、可纯化的目标产物 | 回到 N05 换表达策略或条件 |
| N06 | 判断能不能用 | 产品本身可用，且符合安全与法规要求 | 不通过则终止或退回改造 |

这六件事是主链。**只有需要做选择的地方才是分叉**；每件事内部的实验操作（提质粒、涂板、跑胶、诱导、离心）不单独成节点，挂在对应分叉下面。

## 3. 第二、三层：逐个决策点

> 每个决策点统一写四件事：**问题 / 候选方案 / 判据 / 什么情况下选哪个**。
> 「来源」只标笔记章节与页码范围；页码用于回查，不进入站点正文。

### 3.1 N01 拿到目的基因

**N01 拿到目的基因（第一层分叉）**

- 问题：要研究或生产的基因从哪里来？
- 候选：化学合成、PCR 扩增、基因组文库、cDNA 文库、其他分离技术（扣除文库、差减杂交、mRNA 差异显示、电子克隆、图位克隆）。
- 判据：序列是否已知、有没有模板、片段长度、目标基因是否在特定时期/组织表达、基因组大小、后续要不要建库。
- 选法：序列已知且有模板 → PCR；序列已知但无模板 → 合成；序列未知且要全部基因 → 基因组文库；序列未知但只关心表达基因 → cDNA 文库。
- 来源：ch05 pp.3–51；ch04 pp.108–128；ch02 pp.58–72。
- 待定：ch04 的定点诱变、易错 PCR 属于「已有基因的改造」，第一层没有单列「改造」节点；是否作为 N01 的独立分叉，待定。

**N07 序列/模板已知吗（第二层分叉）**

- 问题：手上有没有目的基因的序列信息，有没有可扩增的模板？
- 候选：已知且有模板、已知但无模板、未知。
- 判据：序列信息、模板来源（基因组 DNA、cDNA、含目的基因的质粒）、两侧引物序列是否已知。
- 选法：有模板且两侧序列已知 → PCR；无模板但序列已知 → 合成；两者都没有 → 建文库钓取。
- 来源：ch05 pp.3–14、pp.15–51。

**N08 合成还是 PCR（第三层分叉）**

- 问题：同样是「已知序列」，用化学合成还是用 PCR 扩增？
- 候选：化学合成（N21）、PCR（N22）。
- 判据：
  - 长度：合成单次最多约 200 bp；超过 200 bp 要分段合成再拼接。
  - 模板：PCR 必须有模板和两侧已知序列；合成不需要模板。
  - 保真度：合成准确性较高、速度快，但单段短；PCR 的保真度取决于聚合酶，笔记把高保真酶单独列为可选项。
  - 成本/通量：笔记没有给出两者的统一成本口径，标「待定」。
- 选法：短片段、无模板、要求序列精确 → 合成；有模板、片段较长、要快速拿到大量拷贝 → PCR；大片段且无模板 → 分段合成 + 拼接。
- 来源：ch05 pp.6–13；ch04 pp.116、pp.1444–1460（PCR 酶选择与比较）。

**N09 基因组文库还是 cDNA 文库（第二层分叉）**

- 问题：序列未知时，是从全基因组里钓，还是从表达产物里钓？
- 候选：基因组 DNA 文库（N23）、cDNA 文库（N24）。
- 判据：
  - 基因组文库：包含全部基因，不含时空特异性；库容量由基因组大小和插入片段决定；覆盖倍数一般要求 4–6 倍。
  - cDNA 文库：只含特定器官/时期表达的基因，具有时空特异性；表达丰度差异大，低丰度基因需要更大库容量；cDNA 多为 0.5–8 kb。
  - 目标：要基因本身、调控序列、物理图谱 → 基因组；要表达基因、避免内含子、做表达谱 → cDNA。
- 选法：目标基因已知在特定组织高表达 → cDNA 文库优先；要拿全套基因或调控序列 → 基因组文库；两者都可行时，按「目标基因是否表达、基因组大小、筛选手段」决定。
- 来源：ch05 pp.15–38。

**N15 文库载体选哪档（第三层分叉）**

- 问题：建库时用哪类载体，才能装下目标片段并保证库的代表性？
- 候选：质粒（<10 kb）、λ 噬菌体（插入型 0–6 kb、置换型 10–25 kb）、黏粒（约 45 kb）、BAC/YAC（100 kb–1 Mb）。
- 判据：插入片段大小、基因组大小、所需覆盖倍数、载体稳定性、后续筛选方式。
- 选法：小基因组或 cDNA → 质粒/λ；35–45 kb 片段 → 黏粒；大基因组、长片段 → BAC/YAC；YAC 要注意基因缺失/重排和与宿主染色体难分离的问题。
- 来源：ch03 pp.59–79；ch05 pp.19、pp.22–24。
- 待定：ch05 文库表写 λ「0–23 kb」，与 ch03 的插入型/置换型容量口径不完全一致；课件原文如此，待核。

### 3.2 N02 装进载体

**N02 装进载体（第一层分叉）**

- 问题：怎么把目的基因放进一个能复制、能筛选、必要时能表达的载体？
- 候选：克隆载体、表达载体、穿梭载体、整合载体；质粒、λ、黏粒、BAC/YAC；黏端连接、平端连接、无缝克隆。
- 判据：插入片段大小、载体容量、宿主范围、筛选标记、酶切位点、连接效率、后续要不要表达。
- 选法：只想扩增/保存 → 克隆载体；要产蛋白 → 表达载体；要跨两种宿主 → 穿梭载体；要整合进染色体 → 整合载体。
- 来源：ch03 pp.4–95；ch06 pp.1–6；ch02 pp.20–72。

**N10 克隆载体还是表达载体（第二层分叉）**

- 问题：这一步的目标是「复制/保存」还是「表达」？
- 候选：克隆载体、表达载体。
- 判据：
  - 克隆载体：有复制起点、标记基因、MCS、较高拷贝数；只要满足「能进、能存、能插、能挑」。
  - 表达载体：在克隆载体基础上增加启动子、终止子、RBS（SD 序列）、MCS，必要时加标签/信号肽；外源基因必须处于启动子控制下并位于正确阅读框。
  - 宿主匹配：表达载体的选择标记必须与受体细胞基因型匹配。
- 选法：建库、亚克隆、保存 → 克隆载体；要产蛋白 → 表达载体；要两种宿主都能用 → 穿梭载体；要稳定整合 → 整合载体。
- 来源：ch03 pp.4–6、pp.80–95；ch07 pp.4–6。

**N11 载体容量选哪档（第二层分叉）**

- 问题：插入片段多大，哪类载体装得下？
- 候选：质粒、λ 噬菌体、黏粒、BAC/PAC/YAC。
- 判据：装载容量、拷贝数、稳定性、导入方式、筛选方式。
- 选法：
  - <10 kb → 质粒；
  - 10–25 kb → λ 置换型；
  - 35–45 kb → 黏粒；
  - 100 kb–1 Mb → BAC/YAC。
- 来源：ch03 pp.59–79；ch05 pp.19。
- 待定：不同笔记页对 λ 容量写法不完全一致（0–6 / 10–25 / 0–23 kb），按「插入型/置换型」区分使用，具体数字待核。

**N16 黏端、平端还是无缝（第三层分叉）**

- 问题：两段 DNA 的末端怎么接？
- 候选：黏性末端连接（N25）、平末端连接（N26）、无缝克隆/接头/同聚物加尾（N27）。
- 判据：
  - 黏端：连接效率较高，要求两端黏端相容；同尾酶切出的相同黏端可以互连。
  - 平端：连接效率低；可通过加大连接酶用量（约黏端的 10 倍）、提高平端底物浓度、加 10% PEG8000、加 NaCl 至 150–200 mM 提高效率。
  - 无缝：In-Fusion 依赖插入片段与线性化载体末端 15 bp 同源；接头/衔接物/同聚物加尾用于没有合适酶切位点的情况。
  - 方向：双酶切可定向克隆；单酶切容易双向插入，需要额外判据。
  - 自连：载体去磷酸化（碱性磷酸酶去除 5′-P）可降低空载自连；多核苷酸激酶可给缺 5′-P 的片段补磷酸。
- 选法：有相容黏端 → 黏端连接；只有平端 → 平端连接并加增强条件；没有合适位点或要求无缝 → 无缝克隆/接头；要定向 → 双酶切。
- 来源：ch02 pp.58–72、pp.100–101；ch06 pp.1–6。

### 3.3 N03 送进宿主

**N03 送进宿主（第一层分叉）**

- 问题：重组分子送进什么细胞，用什么方法送？
- 候选：原核宿主（大肠杆菌、芽孢杆菌）、真核宿主（酿酒酵母、毕赤酵母等）、植物/动物细胞；CaCl₂ 转化、电转化、PEG/Li 转化、农杆菌介导、基因枪、显微注射、病毒转染等。
- 判据：宿主限制/修饰系统、蛋白酶缺陷、标记基因匹配、导入效率、设备与操作复杂度、成本。
- 选法：常规克隆 → 大肠杆菌化学转化；大质粒/高效率 → 电转化；真核表达 → 酵母；植物 → 农杆菌/基因枪；动物 → 脂质体/显微注射/病毒。
- 来源：ch06 pp.7–17；ch07 pp.7–8；ch08 pp.13–24。

**N12 原核还是真核宿主（第二层分叉）**

- 问题：目标蛋白需不需要翻译后修饰、分泌、避免内毒素？
- 候选：大肠杆菌、芽孢杆菌、酵母、植物/动物细胞。
- 判据：
  - 大肠杆菌：遗传背景清楚、繁殖快、成本低、FDA 认可安全；但无翻译后修饰、易形成包涵体、含内毒素。
  - 酵母：能分泌、能糖基化、不产内毒素、GRAS；但酿酒酵母过度糖基化（50–150 个甘露糖残基），毕赤酵母约 8–14 个。
  - 植物/动物：笔记只给转化方法，未给系统的宿主选择判据，标「待定」。
- 选法：无修饰、胞内表达、成本敏感 → 大肠杆菌；需要真核修饰/分泌 → 酵母；需要植物/动物特定背景 → 按 N17 的方法选。
- 来源：ch07 pp.8、pp.33–40；ch08 pp.7–24。

**N17 具体宿主与导入方法（第三层分叉）**

- 问题：在同一类宿主里，选哪个菌株/细胞，用什么方法导入？
- 候选：
  - 大肠杆菌克隆宿主：DH5α、Top10、XL-1 Blue、TG1；
  - 大肠杆菌表达宿主：BL21(DE3)（pET/T7 系统）；
  - 芽孢杆菌：分泌表达；
  - 酵母：酿酒酵母、毕赤酵母、乳酸克鲁维亚酵母、粟酒裂殖糖酵母等；
  - 导入：CaCl₂、电转化、原生质体、PEG/Li、农杆菌、基因枪、显微注射、病毒转染。
- 判据：
  - 宿主：限制酶缺陷、蛋白酶缺陷、标记匹配、无致病性、密码子偏好、能否分泌。
  - 导入：感受态效率（CaCl₂ 可达 10⁷–10⁸ 转化子/μg DNA）、电转参数（E. coli 2.5 kV、Yeast 1.5 kV、0.2 cm 电转杯、40 μL）、设备、操作复杂度、成本。
- 选法：常规克隆 → DH5α/Top10 + CaCl₂；pET/T7 表达 → BL21(DE3)；芽孢杆菌分泌 → 相应宿主；酵母 → 按糖基化/分泌需求选种，再用 PEG/Li 或电转；植物 → 农杆菌/基因枪；动物 → 脂质体/显微注射/病毒。
- 来源：ch06 pp.8–17；ch07 pp.7–8、pp.13–14；ch08 pp.13–24。

### 3.4 N04 确认拿到

**N04 确认拿到（第一层分叉）**

- 问题：怎么证明拿到的是正确的重组子，而不是空载、自连、方向错或带突变的克隆？
- 候选：表型筛选、结构筛选、表达检测、测序验证。
- 判据：载体标记、宿主基因型、插入片段大小、是否有已知序列、检测灵敏度、通量（笔记未系统比较，待定）。
- 选法：常规流程是「表型筛选 → 酶切筛选 → DNA 测序验证」；需要知道是否转录/翻译时再加 Northern/Western。
- 来源：ch06 pp.18–34；ch04 pp.60–99、pp.1444–1535。

**N13 表型筛选还是结构筛选（第二层分叉）**

- 问题：先用选择压力筛，还是直接查分子结构？
- 候选：表型筛选（抗生素抗性、插入失活、α-互补、营养缺陷互补、噬菌斑）、结构筛选（直接电泳、酶切电泳、PCR、Southern）。
- 判据：
  - 表型：只能回答「有没有带上载体/是否插入失活」，不能回答插入方向、片段大小、有无突变。
  - 结构：能回答大小、方向、特异性序列，但需要额外操作。
  - 标准顺序：先表型富集，再结构确认，最后测序。
- 选法：有选择标记 → 先表型；需要区分空载/重组 → 插入失活或 α-互补；片段大小与载体相近 → PCR 或酶切；需要特异性序列 → Southern。
- 来源：ch06 pp.18–31。

**N18 查到 DNA、RNA 还是蛋白层（第三层分叉）**

- 问题：要确认的是「基因在不在」「转录不转录」还是「蛋白有没有」？
- 候选：DNA 层（Southern、PCR、测序）、RNA 层（Northern、RT-PCR/qPCR）、蛋白层（Western、ELISA、免疫筛选）。
- 判据：检测对象、灵敏度、特异性、是否需要定量。
- 选法：查插入/整合 → Southern/PCR；查转录 → Northern/RT-PCR；查翻译 → Western/ELISA；文库筛选 → 原位杂交/免疫筛选。
- 来源：ch04 pp.60–99、pp.128–151；ch06 pp.29–32。

### 3.5 N05 让它表达

**N05 让它表达（第一层分叉）**

- 问题：重组基因进入宿主后，怎么让它高效、可溶、可纯化地表达？
- 候选：非融合表达、融合表达、分泌表达、表面展示；不同启动子与诱导方式；可溶表达或包涵体表达。
- 判据：宿主、启动子强度与渗漏、诱导方式、产物毒性、可溶性、纯化方式、成本。
- 选法：胞内稳定蛋白 → 非融合；要方便纯化 → 融合标签；要分泌 → 信号肽；要展示在细胞表面 → 锚定蛋白融合；高表达形成包涵体 → 复性或改条件。
- 来源：ch07 pp.4–32；ch08 pp.8–25。

**N14 表达策略怎么选（第二层分叉）**

- 问题：用非融合、融合、分泌还是表面展示？
- 候选：非融合表达、融合表达、分泌表达、表面展示表达。
- 判据：
  - 非融合：最接近天然序列，但纯化可能困难。
  - 融合：加 His/GST/内含肽/Profinity eXact 等标签，便于亲和纯化；必要时可切除标签。
  - 分泌：加信号肽，把产物送到胞外，便于纯化；不同蛋白对信号肽效率不同。
  - 表面展示：外源蛋白与锚定蛋白融合，展示在细胞表面。
- 选法：只需拿到蛋白 → 非融合或融合；纯化困难 → 融合标签；产物对胞内有毒/需分泌 → 分泌；做展示/筛选 → 表面展示。
- 来源：ch07 pp.6、pp.19–24；ch08 pp.25。

**N19 可溶表达还是包涵体（第三层分叉）**

- 问题：产物是以可溶形式存在，还是形成包涵体？
- 候选：可溶表达、包涵体表达后复性。
- 判据：
  - 包涵体成因：表达量过高、疏水氨基酸/二硫键/复杂结构域、缺乏翻译后修饰、分子伴侣不足、诱导温度/诱导剂浓度不当、表达定位错误。
  - 包涵体优点：产量高、抗蛋白酶降解、初级纯化简单、对宿主毒性低、便于检测和储存。
  - 包涵体缺点：无生物学活性、需要溶解/复性、复性效率低、工艺复杂成本高、可能产生异构体。
  - 可溶表达：纯化步骤多，但通常不需要复性。
- 选法：产物有活性要求且能可溶 → 优先可溶（降温、降诱导剂、加伴侣、融合标签、分泌）；高表达/毒性大/可接受复性 → 包涵体路线。
- 来源：ch07 pp.25–32。

### 3.6 N06 判断能不能用

**N06 判断能不能用（第一层分叉）**

- 问题：做出来的东西，本身能不能用？能不能放行？
- 候选：产品质量判断（活性、纯度、稳定性）、安全评价、法规与标识、商业化。
- 判据：产品指标、实质等同性、个案分析、熟知性、预防原则、逐步评价、安全等级、法规要求。
- 选法：实验室阶段先判断产品本身；进入释放/商业化前必须走安全评价与审批；不同国家管理模式不同。
- 来源：ch09 pp.1–21。

**N20 安全评价与商业化路径（第二层分叉）**

- 问题：安全评价怎么做，做到什么程度才能商业化？
- 候选：安全评价（实质等同、个案分析、熟知性、预防、逐步）、安全等级/实验室等级（BSL-1–4）、管理模式（产品基础/技术基础/两者之间）、标识制度、五阶段审批。
- 判据：
  - 受体生物学特征与基因操作的风险 → 四个安全等级（尚不存在危险、低度、中度、高度）。
  - 产品用途与释放环境 → 实验室研究、中间试验、环境释放、生产性试验、生物安全证书。
  - 国家管理模式：美国/加拿大偏产品，欧盟偏技术，中国是产品 + 过程。
  - 标识：中国按目录定性强制标识，第一批 5 类 17 种。
- 选法：任何转基因产品在释放前先做安全评价；按风险定安全等级；按国家法规走审批与标识；商业化要看是否拿到安全证书和生产许可。
- 来源：ch09 pp.8–16。
- 待定：笔记只给「全过程一般 6–8 年」和已商业化作物例子，未给不同产品类别的完整审批清单；细化清单待定。

## 7. 跟课程章节顺序的差异

### 7.1 顺序差异

课程顺序是：绪论 → 工具酶 → 载体 → 常用技术 → 目的基因获取 → 重组操作 → 原核表达 → 酵母表达 → 安全。

决策树顺序是：**目的 → 载体 → 宿主 → 确认 → 表达 → 评价**；工具酶、载体、技术不再单独成章，而是被拆进需要它们的分叉。

典型差异：

- 工具酶不再从「酶的分类」讲起，而是从「这一步需要切开/连接/扩增/修饰，选哪种酶」进入。
- 载体不再按「质粒→λ→M13→黏粒→BAC/YAC」讲，而是先问「装多大、进什么宿主、要不要表达」，再选容量档。
- 常用技术不再按「提取→电泳→杂交→PCR→测序→诱变」讲，而是按「验证 DNA/RNA/蛋白」分流。
- 原核/酵母表达不再按物种分章，而是合并成「选宿主」与「选表达策略」两个分叉。

### 7.2 章节内容被拆到哪些决策下

| 章节 | 课程里的位置 | 拆到哪些决策 | 拆分说明 |
|---|---|---|---|

### 7.3 这样拆的代价

- 同一实体（如限制酶、pUC、pET）会出现在多个决策下；数据层必须用**实体 id** 去重，图上的锚点只画一次。
- 课程里的「章」不再是导航单位，来源只作为 `sources` 定位。
- 某些内容在决策树里没有天然落点（如发展史、应用案例、其他基因分离技术），只能作为概念注记或档案 `note`，不强行造节点。
