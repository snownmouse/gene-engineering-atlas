# 「基因工程 · 工艺链」首页视觉参考

用途：为首页「六站主线（切→接→转→增→检→养）+ 被否岔路 + 判据 + 产出物」找可借鉴的视觉处理，重点解决「太单调」。

检索方向覆盖：技术路线图 / 知识地图 / 工程手册跨页 / 工艺流程海报 / 操作序列信息图。

访问说明：下列链接均在 2026-11-11 实际打开核验；页面内的图片在抓取环境中未逐张渲染，外观描述依据页面文字说明与作品公开信息。未找到可核验、且不属于模板站或 AI 生成图的中文「工艺流程海报」，故中文语境部分改用古籍工序版画与营造图样，不编造作品名。

## 01 NASA：阿波罗登月三种方案的取舍图（1962）

链接：https://www.nasa.gov/history/60-years-ago-nasa-decides-on-lunar-orbit-rendezvous-for-moon-landing/
作者/机构：John Uri，NASA 约翰逊航天中心（2022 年回顾文章，内含 1962 年原始示意图）

**可借鉴**：这是与首页结构最接近的一张图——三条并列路线画在同一张图上，被否掉的「直接上升」「地球轨道交会」没有被删掉，而是保留完整走向、在分叉口旁边写清否决理由（研制周期、成本、风险、需不需要新火箭）。判据贴着分叉点写，不塞进图例。
**别照搬**：原始示意图线条粗细基本一致、没有字号层级，直接搬会像说明书插图；而且它只画「方案」，没有「每站产出物」这一层。

## 02 Massimo Vignelli：纽约地铁线路图（1972）

链接：https://www.moma.org/explore/inside_out/2014/06/23/the-subway-and-the-city-massimo-vignelli-1931-2014/
作者/机构：Massimo Vignelli（Unimark International），MoMA 收藏

**可借鉴**：线只承担一种语义——颜色代表线路归属，转角统一 45°/90°，站点只用两种符号（普通站实心点、换乘站空心圈）就拉开了层级；地理被主动压缩，换取阅读顺序。这套「线型语义 + 两种节点符号」可以直接搬到主线上。
**别照搬**：它没有「产出物」和「判据」的位置，纯线网会把工艺链压成地铁图，六站的产出物会全部丢失；这种极度理性的等宽线在暗底上也容易显得冷。

## 03 CERN：加速器复合体主链图

链接：https://home.cern/science/accelerators/accelerator-complex
作者/机构：CERN（图源 CERN Graphics，CDS 编号 CERN-GRAPHICS-2022-001-1）

**可借鉴**：一条主链（Linac4→PSB→PS→SPS→LHC）用较粗的线贯穿，多个实验支线从主链上斜向分出、用细线、末端自然收住；每个节点旁只标一句关键参数（能量、周长）。这正是「主线 + 岔路」的现成范式，且是深色底。
**别照搬**：原图文字极小，是给内行看的示意图；首页若照搬这种密度，站名和产出物会看不清。另外它的支线是「并行的实验」而非「被否的方案」，岔路的语义要自己重做。

## 04 Dominic Walliman：数学地图（Domain of Science）

链接：https://store.dftba.com/products/map-of-mathematics-poster
作者/机构：Dominic Walliman（Domain of Science）

**可借鉴**：深蓝近黑的底 + 分区高饱和色，主干粗、末梢细，分支长度按内容量分配而不是等距——这是「不单调」最直接的手段：让线的长短、粗细本身携带信息。标题层级靠字号拉开，不靠色块。
**别照搬**：它的分支有几十条，靠密度撑住画面；首页只有六站，直接套用会显得空。它也没有「否定」的视觉语言，所有分支都是正向展开。

## 05 NASA：阿波罗 11 号飞行计划（1969）

链接：https://www.nasa.gov/wp-content/uploads/2025/11/a11fltpln-final-reformat.pdf
作者/机构：NASA 载人航天中心飞行计划处（Flight Planning Branch），1969-07-01

**可借鉴**：跨页用「时间轴 + 表格网格」双栏排布，页眉页脚固定，编号系统（1-1、1-5）让读者能定位；密集信息段与大片留白交替出现，形成翻页节奏。适合借鉴「每条工艺段既有图形又有一小段参数表」的组织方式。
**别照搬**：它是纯文档，几乎没有主视觉；首页照搬会变成说明书。表格的等宽栅格也会把「非等距」的意图抹平。

## 06 《天工开物 · 杀青》造竹纸工序图（1637）

链接：https://commons.wikimedia.org/wiki/File:Making_Paper.gif
作者/机构：宋应星（明），Wikimedia Commons 扫描件

**可借鉴**：一幅图内并置多道工序（斩竹、漂塘、煮楻、抄纸、焙干），用人物动作作为节点锚点，不用箭头也能读出先后；无透视、平面展开，上方标题、下方说明，图与文分离得很干净。
**别照搬**：木刻线条粗细单一，没有「失败路径」的概念，也没有现代意义上的标注系统；直接放大到网页会显得灰、缺对比。

## 07 《营造法式》图样（1103）

链接：https://commons.wikimedia.org/wiki/Category:%E7%87%9F%E9%80%A0%E6%B3%95%E5%BC%8F
作者/机构：李诫（北宋），Wikimedia Commons 影印本

**可借鉴**：引线标注体系——构件用细线画出，名称和尺寸用长引线拉到图外空白处，留白本身就是分隔；同一构件在不同图里分层拆解（整体→分件），读者可以逐层下钻。
**别照搬**：纯黑线稿在屏幕上对比过强，需要压到 60%–70% 黑；另外它是「静态图样」，没有状态和流程顺序。

## 08 W.E.B. Du Bois：1900 年巴黎博览会统计图版

链接：https://www.loc.gov/item/2013650371/
作者/机构：W.E.B. Du Bois 与亚特兰大大学学生，美国国会图书馆藏（LOT 11931）

**可借鉴**：米色纸底 + 黑、赭、砖红三色，手绘线的宽度不完全均匀，反而有温度；一页一图但共享同一套版式，翻页时有节奏而不散。这套「纸感底 + 三色上限 + 手绘不等宽」很适合用来中和工程图的冷。
**别照搬**：它是统计图不是流程图，圆形和条形编码无法直接对应工序；手绘感如果模仿过头会变成复古装饰。

## 综合建议：首页往哪个方向收

**不要做「六等分卡片 + 箭头」的流程条**，那是单调的根源。建议收成一张**横向、非等距的工艺长图**：

- **主线**：一条连续的粗线贯穿六站，站与站之间的线段长度按该段信息量分配（切→接、接→转信息多就长，检→养信息少就短），不做等距。
- **站点**：每站是一个「工位」而不是圆点——站名最大，产出物作为小号标签挂在站体下方，判据写在站与站之间的线上（线上方是判据名，线下方一句取舍），判据不进入图例。
- **岔路**：从站点斜向分出，线更细、颜色降一档、末端用短横收住，旁边用最小字号写「为何否」。被否不等于消失，只是退后一层——这是 NASA 那张图最值得学的一点。
- **层次**：至少四级字号（站名 / 产出物 / 判据 / 岔路注），靠字号和线宽制造主次，不靠色块和阴影。
- **底色**：建议**深墨蓝底 + 暖白主线 + 单一琥珀强调色**（来自 CERN 与数学地图），让主线发亮、岔路自然退后；详情层和站点卡片改用米白纸感（来自《天工开物》《营造法式》与 Du Bois），形成材质对比。全站颜色控制在三色以内。
- **留白**：靠「站距不等」和「岔路长短不一」制造，不要靠均匀的卡片间距；段与段之间可以整段留空，让视线有停顿。

一句话：**用一条不等距的主线撑骨架，用线宽和字号分层，用「退后一档」的细线处理被否的岔路，底色在深墨蓝与纸白之间做材质对比。**
