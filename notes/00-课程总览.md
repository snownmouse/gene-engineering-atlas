## 结论先行

1. 全课是一条**单线流水**：`第一章定总纲 → 二/三/四章备工具 → 五、六章走流程 → 七、八章做产品 → 九章收边界`。九章不是并列关系，前四章是后五章的前置。
2. 三件套（工具酶、载体、常用技术）分别解决**切/接/改**、**运载**、**检测**，缺任何一件，第五、六章都无法成立。
3. 第五、六章是全课**唯一完整走完「切—接—转—检」**的部分；第七章起只强调「养」与产物，不再重复前端操作。
4. 跨章重复最多的四个概念是：**限制酶、载体、α-互补、表达系统**；其中 3 处存在**跨章口径不一致**（见第三节 ⚠️ 标记）。
5. 九章共汇总疑点 **31 条**：硬错 12、可能笔误/待核 9、渲染与遮挡 10（见第四节）。

## 三、跨章串联点

### 1. 限制性内切酶（ch01 / ch02 / ch03 / ch04 / ch05 / ch06）

| 章 | 页码 | 讲到什么深度 |
|---|---|---|
| ch01 | p.28、易混点 8 | 只作为「切」的代名词出现，一句话级 |
| **ch02** | 全章 pp.3–57 | **最全**：发现史、命名、四型系统、识别序列、末端类型、同裂酶/同尾酶、位点偏爱、星活性、缓冲液与温度 |
| ch03 | p.2、pp.18–31 | 只讲**用途**：MCS 必须是单一识别位点；插入失活用酶切位点破坏标记基因 |
| ch04 | p.92、pp.174–176 | 作为**工具**：Southern 探针制备时酶切；定点诱变中引入或消除酶切位点 |
| ch05 | p.19 等 | 用酶把基因组切成一定长度范围以建库 |
| ch06 | pp.3–4 | 给出**选酶三原则**：MCS 处与基因两端都有、必须是单一、能重新切回 |

- **互补**：ch02 给性质，ch03 给位点约束，ch06 给选择标准，ch05/ch04 给具体场景。
- **口径冲突** ⚠️：III 型酶切割位点，ch02 p.14 写「下游 25–27 bp」，p.16 比较表写「24–26 bp」（见 H3）。

### 2. 载体（ch01 / ch03 / ch05 / ch06 / ch07 / ch08）

- ch03 是**唯一系统讲载体分类**的章：克隆载体（质粒→λ→M13/噬菌粒→黏粒/BAC/PAC/YAC）与表达载体（含穿梭、整合），pp.2–95。
- ch05 只讲**文库该配什么载体**：基因组文库用 λ/质粒，cDNA 文库因片段 0.5–8 kb 常用质粒或噬菌体类（pp.19、pp.36–37）。
- ch06 只讲**选载体要考虑宿主与片段长短**（p.3）。
- ch07/ch08 只讲**表达载体**：pET/pGEX/pHsh/pCold（ch07 pp.13–18）、pYES/YEp/pPICZα（ch08 pp.16–24）。
- **口径不一致** ⚠️：
  - ch01 易混点 7 把载体写成「质粒、λ、单链丝状噬菌体；大肠杆菌表达载体、穿梭载体、整合载体」，与 ch03 p.3 的「克隆载体 / 表达载体」二分法**分类维度不同**，复习时以 ch03 为准。
  - λ 文库插入片段：ch05 p.19 写「0–23 kb」，ch03 pp.40–48 写插入型 0–7.2 kb、置换型 10–25 kb（见 H2/H11）。

### 3. α-互补 / 蓝白斑（ch03 / ch05 / ch06）

- ch03 p.22 讲**机制**：lacZΔM15 提供 ω 片段，lacZ′ 编码 140 aa 的 α 片段并带 MCS；互补显蓝，插入即白。
- ch06 p.22 讲**操作流程**：IPTG/X-gal 平板，蓝=空载、白=重组体；口径与 ch03 一致。
- ch05 p.39 只在筛选策略表里**列名**，不展开。
- 结论：三章无矛盾，深度为 ch03（原理）> ch06（操作）> ch05（点名）。

### 4. PCR（ch04 / ch05）

- ch04 pp.105–154 是**唯一系统讲 PCR** 的地方：原理、体系、程序、产物克隆（T 载体 p.122）、RT-PCR、qPCR、其他类型（p.153）。
- ch05 p.14 只有 1 页，明确「PCR 原理与条件见第四章」，本章只强调**前提是已知两侧序列**。
- 结论：无冲突，属**有意分工**；复习 PCR 一律回 ch04。

### 5. 转化 / 导入与受体细胞（ch03 / ch06 / ch07）

- ch06 pp.7–17 讲**方法**：CaCl₂ 法、电转化、农杆菌、基因枪、显微注射、原生质体融合。
- ch07 p.7 讲**宿主标准**：易接纳 DNA、限制酶缺陷型、无致病性、蛋白水解酶缺失、密码子无偏好等 9 条。
- ch03 pp.85–86 讲**穿梭载体**如何跨两类宿主。
- 互补关系：方法（ch06）+ 宿主条件（ch07）+ 运载工具（ch03），三处合起来才是完整的「转」。

### 6. 表达系统（ch03 / ch07 / ch08）

| 章 | 页码 | 内容层次 |
|---|---|---|
| ch03 | pp.81–84 | **一般原则**：正确阅读框架、强启动子、转录延伸与终止、SD（原核）/Kozak（真核）、终止码优选 UAA、避免降解（融合/分泌/包涵体） |
| ch07 | pp.8–46 | **原核落地**：大肠杆菌优劣势、启动子类型（lac/trp/tac/trc、T7、λP_L）、RBS 间距 3–11 bp、pET/pHsh/pCold、GST/His 纯化、包涵体复性、芽孢杆菌、胰岛素实例 |
| ch08 | pp.8–31 | **真核落地**：穿梭载体、AOX1、酿酒酵母 vs 毕赤酵母、糖基化（50–150 vs 8–14 个甘露糖）、表面展示 |

- 互补：ch03 给判据，ch07/ch08 给两套实现。
- **口径提示**：ch03 p.84 举例 pPIC9K（9.3 kb），ch08 用 pPICZα（3.6 kb，ch03 pp.85–86 也列有），两者是**不同载体**，不要混为同一质粒。
- **笔误** ⚠️：ch07 p.46「在大肠杆菌或酵母粉等工具中表达」，「酵母粉」应为「酵母」（T3）。

### 7. 基因文库与载体容量（ch03 / ch05）

- ch05 pp.15–38 讲**建库流程**（基因组文库、cDNA 文库、滴度与代表性）。
- ch03 pp.59–79 讲**容量阶梯**：λ → 黏粒 → BAC → PAC → YAC。
- **跨章冲突** ⚠️：λ 插入片段 0–23 kb（ch05 p.19）vs 0–7.2/10–25 kb（ch03 pp.40–48）。
- **章内冲突** ⚠️：BAC/YAC/PAC 容量在 ch03 内部三处不一致（H6–H8）。

### 8. 筛选与鉴定体系（ch03 / ch04 / ch05 / ch06）

- ch03 pp.18–31：**标记基因**本身（抗性、营养缺陷、supF、sacB、lacZ′、GFP）。
- ch06 pp.18–34：**筛选方法总装**（载体表型、结构特征、核酸杂交、免疫化学、其他）。
- ch05 pp.39–51：**文库级筛选**（菌落/噬菌斑杂交、混合池 PCR、酵母双杂交）。
- ch04：提供底层手段（电泳 pp.34–57、杂交 pp.58–104、PCR、测序 pp.155–168）。
- 深度排序：ch06（方法学总表）> ch05（文库场景）> ch03（元件）> ch04（底层技术）。

### 9. 胰岛素案例（ch01 / ch07）

- ch01 p.20 用两条路线做**导入性案例**：cDNA 路线、A/B 链分别融合表达路线。
- ch07 pp.42–46 把同一案例**讲透**：A 链 21 aa、B 链 30 aa、C 肽、两对链间二硫键（A7–B7、A20–B19）、AB 链合成法与胰岛素原法、1982 年 Humulin 上市。
- 结论：内容一致，ch07 更细；复习时以 ch07 为准，ch01 只记「有两条路线」。

### 10. 安全（ch01 / ch09）

- ch01 pp.43–45 只有一节，点到「基因工程的安全」。
- ch09 全章展开：争议事件（p.2–7）、DNA 重组生物安全准则（p.8–9）、评价原则（p.10）、三种管理模式与标识制度（pp.11–16）、产业与前景（pp.17–21）。
- ch09 p.19「**风险 ≠ 有害**」是全课唯一的方法论金句，可作为安全类问答的总纲。
